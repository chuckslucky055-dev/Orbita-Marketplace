# Orbita Marketplace

A responsive ecommerce marketplace concept featuring product discovery, category filters, search, sorting, deals, wishlist, cart drawer and a guarded demo checkout.

**Live demo:** https://orbita-marketplace-pnh060.v2.appdeploy.ai/

## Run locally

```bash
npm install
npm run dev
```

All catalogue items, prices and offers are illustrative. No live orders or payments are processed.
